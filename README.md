# 🏥 Hospital ER Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **Hospital Emergency Room Analytics
Dashboard** developed using **Microsoft Fabric, Azure SQL Database, and
Power BI**.

The dashboard provides insights into **ER visits, patient volume,
average wait time, length of stay, patient types, gender distribution,
and department performance**.

## 🛠️ Tools Used

-   Microsoft Fabric
-   Azure SQL Database
-   Power BI
-   DAX
-   Fabric Lakehouse
-   Dataflow Gen2
-   Data Cleaning
-   Data Visualization
-   Excel / CSV

## 📈 Key KPIs

-   Total ER Visits -- **25,430**
-   Total Patients -- **18,920**
-   Average Wait Time -- **32 min**
-   Average Length of Stay -- **4.2 days**

-   Interactive Hospital ER Dashboard

-   ER Visits Trend Analysis

## 📌 Project Objective

To transform hospital emergency room data using **Azure SQL Database,
Microsoft Fabric, and Power BI** into an interactive dashboard that
helps users **monitor key performance indicators, analyze patient
trends, evaluate department performance, and understand hospital
operations**.
